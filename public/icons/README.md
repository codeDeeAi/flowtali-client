# PWA Icons

Place the following icon files here:

- `icon-192.png` — 192×192 px, used for Android home screen and notification icons
- `icon-512.png` — 512×512 px, used for splash screens and high-res displays

Both should be square PNGs with a transparent or branded background.
The `icon-512.png` is also used as the maskable icon (ensure important content is within the inner 80% safe zone).
